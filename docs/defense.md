# Ответы на контрольные вопросы

1. **Какие входные данные получает приложение и где они находятся?**
   Файлы `data/employees.csv` и `data/form_cases.json`, GET-параметр `department` (фильтр) и POST-поля формы (`name`, `email`, `department`, `experience`).

2. **Какой участок кода преобразует данные в интерфейс?**
   Функции из `src/functions.php` готовят данные (`loadEmployees`, `makeEmployee`, `validateInput`), а HTML-часть `public/index.php` ниже PHP-блока выводит их через `e()`.

3. **Какое ошибочное состояние проверялось вручную?**
   Пустое ФИО, неверный email, стаж `-2` или `abc`, неизвестный отдел в фильтре, отсутствующий `employees.csv`.

4. **Что изменить при росте проекта?**
   Разделить код на слои (MVC), вынести чтение данных в отдельные классы, заменить CSV базой данных, добавить redirect после POST и сохранение заявок.

5. **Как проверить работу после чистого клонирования?**
   `git clone`, затем `php -S localhost:8000 -t public`, затем пройти `docs/checklist.md`.

6. **Чем серверное выполнение PHP отличается от JavaScript в браузере?**
   PHP выполняется на сервере, браузер получает уже готовый HTML. JavaScript выполняется в браузере пользователя. Поэтому валидацию на сервере нельзя обойти отключением JavaScript.

7. **Когда полезен конструктор класса?**
   Когда объект нужно сразу создать в корректном состоянии: обязательные значения передаются при создании. В этой работе классов нет, конструкторы появятся в следующих.

## Дополнительно для защиты

**Почему валидация на сервере?** Браузерные проверки можно обойти, серверной можно доверять. Поэтому в форме стоит `novalidate`, а все проверки выполняет `validateInput()`.

**Почему trim перед проверкой?** Строка из пробелов не должна считаться заполненной. После `trim` она становится пустой и получает ошибку «Введите ФИО».

**Зачем оператор `??`?** `$_POST['name'] ?? ''` не вызывает notice, если поля нет в запросе, и подставляет пустую строку.

**Почему показ ошибок включён только локально?** Сообщения об ошибках могут раскрыть пути к файлам и детали кода. На рабочем сервере их показывать нельзя.

**Показать использование dataset:** изменить в `data/employees.csv` стаж или отдел сотрудника и обновить страницу: таблица, средний стаж и список отделов изменятся без правок кода.
